# 小黄本课程逐页深度地图：36 页到 OLIF 的转译

这是 `xiaohuangben-content-models.md` 的逐页深层配套。普通的形式判断先读快速版；复杂脚本需要混合结构、安全改造或追溯课程页时，再读本文件。内容经过转述，不复刻私有课件原文。

每张卡记录四件事：本页在课程中的作用、值得保留的变量、如何转成中国老板关心的出海内容、哪些做法需要改造或弃用。六个章节分别是：

1. 定位与观看理由：`XHB-01`–`XHB-07`
2. 文案基础：`XHB-08`–`XHB-10`
3. 观点：`XHB-11`–`XHB-16`
4. 过程：`XHB-17`–`XHB-22`
5. 知识：`XHB-23`–`XHB-29`
6. 故事：`XHB-30`–`XHB-36`

## 第一章：定位与观看理由

### XHB-01 — 课程总导航

- **保留：**先判断内容任务，再选择主导容器；流量/信任/转化是任务，观点/过程/知识/故事是表达工具。
- **OLIF 转译：**一个视频只承担一个首要任务，并让一个容器主导。
- **改造：**不能把课程目录误当成每次都要完整执行的流水线。

### XHB-02 — 定位章节页

- **保留：**形式优化之前，先确认在为谁解决什么问题。
- **OLIF 转译：**稳定中轴是“正在做海外决策的中国老板”；市场和服务可以变化。
- **改造：**章节页只有导航作用，不是独立写作方法或证据。

### XHB-03 — 三种观看回报

- **保留：**有用、好奇、共鸣；条件允许时组合两种。
- **OLIF 转译：**海外反常识带来好奇，决策规则带来有用，精准说出老板压力带来共鸣。
- **改造：**“介绍我们的业务”不是观看理由；强知识题不必硬塞情绪。

### XHB-04 — 给观众一个进入理由

- **保留：**任何题都要快速说明受众利害或承诺回报。
- **OLIF 转译：**在说国家或服务前，先说预算浪费、订单延迟、伙伴风险、信誉或机会成本。
- **改造：**开头承诺不能大于正文的实际交付。

### XHB-05 — 多种注意力入口

- **保留：**结果、冲突、成本、身份、陌生感、变化和权威等只是可选入口，应与证据自然匹配。
- **OLIF 转译：**优先使用经核实的结果、老板冲突、市场反差、隐藏成本和重大变化。
- **改造：**不堆叠刺激点，不做虚假第一，也不用性暗示和地位炫耀破坏专业信任。

### XHB-06 — 多维、原生与高频

- **保留：**账号要呈现多个可信侧面，素材来自真实工作，并通过足够发布量获得反馈。
- **OLIF 转译：**轮换商业判断、现场过程、案例教训和人物故事，但受众与判断中轴保持一致。
- **改造：**频率永远不能压过事实核验、客户保密和基本内容价值。

### XHB-07 — 四种容器与高关注元素

- **保留：**用观点、过程、知识、故事承载题目；成本、人物、反常识、最坏后果、今昔变化和头部做法可增强注意。
- **OLIF 转译：**对应到海外预算、经销商、当地消费者、陌生规则、失败路线和市场变化。
- **改造：**弃用荷尔蒙、羞辱、假冲突、假排名等不适合 B2B 的捷径。

## 第二章：文案基础

### XHB-08 — 文案章节页

- **保留：**结构和措辞要让观点更容易被看见、理解和感受。
- **OLIF 转译：**战略判断选定后，把它变成可观察的商业行为与后果。
- **改造：**漂亮措辞救不了弱选题。

### XHB-09 — 从私人想法到公共表达

- **保留：**灵感属于创作者，语境、矛盾和回报属于观众；两者要经过翻译。
- **OLIF 转译：**把“东南亚有机会”改成谁现在该关心、在什么条件下成立、会改变哪个决定。
- **改造：**一个论点能讲清时，不发布完整思考日记。

### XHB-10 — 让语言有画面和力量

- **保留：**具体描述、有效比喻、生活语言和有意义的前后/预期现实反差。
- **OLIF 转译：**说清买家、经销商或当地团队实际做了什么，少用机构黑话。
- **改造：**不堆装饰比喻，不抄标志性类比，不装方言，不虚构数字反差。

## 第三章：观点

### XHB-11 — 观点章节页

- **保留：**观点内容必须围绕真实矛盾，提出能够被论证的判断。
- **OLIF 转译：**只有能改善老板决策的立场才值得拍，不为评论区强行站队。
- **改造：**语气强不等于观点成立。

### XHB-12 — 寻找矛盾

- **保留：**从人物、冲突和事件中找题，再用愿望、坏后果、对立、意外或责任增强利害。
- **OLIF 转译：**可用老板假设与当地消费者、短期订单与长期渠道、国内成功者与海外新手等矛盾。
- **改造：**不虚构阵营，不揣测动机，不无证据归罪可识别个人。

### XHB-13 — 判断的四类对象

- **保留：**行业、产品、从业者和客户都能成为观点对象，但要明确批评或支持的是哪种具体行为。
- **OLIF 转译：**批评一条路线或采购决策，不羞辱国家、客户群、同行和老板本人。
- **改造：**市场观察不能偷换成“所有当地人都如此”。

### XHB-14 — 直接、归纳与对比论证

- **保留：**选最短且真正支持结论的论证方式，可用直接证据、多个案例或公平对比。
- **OLIF 转译：**按成本、时间、控制和风险比较路线，并用案例说明适用条件。
- **改造：**单个轶事不能证明普遍规律；对比维度必须一致。

### XHB-15 — 证据与表达压力

- **保留：**可从得失、现实限制、不同利益相关者和长期后果加固判断。
- **OLIF 转译：**同时看老板、经销商、当地买家、达人和团队的约束，说明做与不做的差别。
- **改造：**弃用人身攻击、甩锅、羞辱和为了赢而偷换维度。

### XHB-16 — 观点的完整路径

- **保留：**矛盾 → 单一判断 → 证据 → 适用边界或下一步。
- **OLIF 转译：**开头给老板决策，尽早交付证据，最后说清何时不适用。
- **改造：**不先堆履历；流量或信任任务不强塞销售结尾。

## 第四章：过程

### XHB-17 — 过程章节页

- **保留：**过程只有在结果、验证或选择具有不确定性和后果时才有观看价值。
- **OLIF 转译：**市场研究、电话、达人筛选、拜访、网站审查和项目复盘都可成为专业判断证据。
- **改造：**忙碌蒙太奇不是过程故事。

### XHB-18 — 四类过程素材

- **保留：**工作、变化、挑战、关系或事件推进，都要有可见起点和变化。
- **OLIF 转译：**优先拍真实专业过程：市场筛选、伙伴评估、谈判、活动搭建与复盘。
- **改造：**摆拍公益、恶作剧和无关挑战不适合 OLIF。

### XHB-19 — 火车头与车厢模型

- **保留：**强目标是火车头，步骤是车厢；只保留改变决定、增加悬念或展示专业性的步骤。
- **OLIF 转译：**先给商业后果，再展示真正影响市场、伙伴、信息或预算的少数动作。
- **改造：**不能因为拍到了就把所有执行步骤都塞进视频。

### XHB-20 — 预期装置

- **保留：**真实目标、限制、分歧、未知结果或验证任务能够产生前进动力。
- **OLIF 转译：**可用固定预算、截止时间、市场争议、伙伴核验或尚未验证的当地反应。
- **改造：**不虚构客户阻碍、内部冲突和时间压力。

### XHB-21 — 过程推进

- **保留：**起始条件 → 决定性动作 → 阻碍或发现 → 结果或下一决策；每一拍都要改变观众认知。
- **OLIF 转译：**说清拒绝了什么、哪条证据改变计划、还有什么未知。
- **改造：**多方参与的结果不能被写成 OLIF 单一因果。

### XHB-22 — 过程拍摄路径

- **保留：**拍前先定义故事，抓决定时刻，旁白只补画面缺失的信息。
- **OLIF 转译：**围绕文件、屏幕、电话、地点、反应和决策变化设计镜头，并遮蔽敏感内容。
- **改造：**没有许可不得暴露客户数据、私信、人脸和位置。

## 第五章：知识

### XHB-23 — 知识章节页

- **保留：**知识只有改变观众行动或判断时才有价值。
- **OLIF 转译：**教学落在市场选择、第一笔预算、渠道匹配、伙伴核验和风险预防上。
- **改造：**术语堆砌和通用清单不算有用知识。

### XHB-24 — 五种知识结果

- **保留：**改善结果、解决问题、避坑、降低成本或获得可转述的解释；写前选一个主结果。
- **OLIF 转译：**帮助老板选择、排序、预算、验证或解释一个海外决定。
- **改造：**不能假装复杂出海问题总有三步通解。

### XHB-25 — 解决问题结构

- **保留：**可识别情境 → 后果 → 真正诊断 → 可执行回应。
- **OLIF 转译：**“海外投放贵”可能是产品、信息、追踪或渠道错配，先教观众区分。
- **改造：**不给脱离市场、阶段和证据前提的处方。

### XHB-26 — 推荐结构

- **保留：**先定义人群与收益，再按有意义的标准排序，并给适用条件。
- **OLIF 转译：**市场、渠道、工具和第一步按公司阶段、产品、预算、控制和风险推荐，不按热度。
- **改造：**拒绝带货式罗列、虚假权威和无依据排名。

### XHB-27 — 机制或风险揭示

- **保留：**可见问题 → 激励或机制 → 后果 → 应对方法。
- **OLIF 转译：**解释经销商、当地达人、平台或买家为何如此行动，区分已证实机制与推断。
- **改造：**不把动机猜测当事实，也不制造阴谋提高留存。

### XHB-28 — 案例带出规则

- **保留：**简短案例 → 决定性变量 → 可迁移规则 → 适用边界。
- **OLIF 转译：**客户是主角；确认授权和数字，区分 OLIF、客户及外部因素的贡献。
- **改造：**不虚构效果，不改写事实时间线，不让单个成功代表整个市场。

### XHB-29 — 知识的完整路径

- **保留：**题目、承诺、结构、例子和行动成本一致；先给第一份有效答案，再补条件和案例。
- **OLIF 转译：**一个视频改善一个决定，结尾给成本最低但合理的下一步。
- **改造：**低行动成本不等于过度简化；知识内容不必每次硬转化。

## 第六章：故事

### XHB-30 — 故事章节页

- **保留：**故事通过人物、压力、选择和后果承载判断。
- **OLIF 转译：**只有人的决策比直接解释更能承载商业洞察时才讲故事。
- **改造：**戏剧性不能替代证据和受众相关性。

### XHB-31 — 小成功故事

- **保留：**真实起点劣势 → 具体行动 → 阻碍 → 挣来的变化。
- **OLIF 转译：**首个有效询盘、纠正一个市场假设或避免一次损失，常比巨额收入更可信。
- **改造：**不夸大结果，不抹去伙伴贡献。

### XHB-32 — 成功案例故事

- **保留：**初始问题、关键选择、复杂情况和可衡量后果组成完整弧线。
- **OLIF 转译：**使用确认过的客户事实，并拆清 OLIF 做了什么、客户做了什么、哪些不能做因果归属。
- **改造：**具名事实案例不能混入合成细节，也不能制造奇迹结局。

### XHB-33 — 普通人英雄故事

- **保留：**普通人物在压力下做出有代价的原则性选择，由后果完成意义。
- **OLIF 转译：**当地员工、伙伴、买家或老板都能揭示文化与商业现实，不需要名人。
- **改造：**要授权或匿名，不能把 OLIF 写成拯救别人故事的英雄。

### XHB-34 — 困难组合

- **保留：**外部限制、内部冲突、关系压力或反复失败中，只选真正改变选择的障碍。
- **OLIF 转译：**预算、时间、信息、法规、团队分歧和渠道依赖已经足够形成压力。
- **改造：**拒绝添加没有发生的灾难、背叛、贫困、疾病和羞辱。

### XHB-35 — 转折组合

- **保留：**新发现、新决定、他人帮助、结果反转或重新理解都能形成转折；一个挣来的转折已经足够。
- **OLIF 转译：**新市场证据、买家反应、伙伴提问或被推翻的假设都可成为转折。
- **改造：**不用巧合救场，也不虚构 OLIF 单独拯救项目。

### XHB-36 — 故事的完整路径

- **保留：**真实压力 → 选择 → 复杂情况或发现 → 回应 → 后果 → 挣来的洞察。
- **OLIF 转译：**事实型信任内容保护时间线和授权；流量型创作可虚构或合成，但可核实的第三方事实必须匿名/假设化，并给用户后台标签。
- **改造：**不强塞道德总结、销售动作、额外反转和事件没有支撑的宏大意义。

## 跨章节组装规则

- 先定战略任务，再定一个主导容器。只有副容器能加强证据时才混合，例如观点+案例、过程+知识、故事+决策规则。
- 流量题可用故事或观点提高传播，但事实边界仍然有效；信任题通常需要真实过程、案例或一手证据；转化题必须说明适用条件和下一步。
- 注意力元素只用来放大已有后果，不用来注入奇观；语言技巧只用来解释观点，不用来模仿来源声音。
- 课程的一般创作者技巧若与 OLIF 的 B2B 信任、客户保密、原创独立或事实边界冲突，以 OLIF 规则为准。
- 应用任何逐页方法后，回到 `content-method.md` 检查受众利害、承诺兑现、证据、口语感和事实安全。
