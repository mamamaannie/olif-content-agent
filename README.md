# OLIF 出海内容 Agent

这是杜俣桐 Olif 的个人 Codex Skill，用于出海短视频选题、热点研究、对标拆解、口播脚本、拍摄卡与数据复盘。

## 安装

将整个仓库克隆或复制到：

```text
~/.codex/skills/olif-content-agent
```

重启 Codex 后，可以直接说：

- “帮我判断这个出海想法值不值得拍。”
- “查一下最近适合中国老板看的出海热点。”
- “把这段想法整理成一条能拍的口播。”
- “拆解这个对标视频，但不要洗稿。”

也可以显式调用 `$olif-content-agent`。

## 隐私与资料

仓库包含经过整理的方法论、创作者档案和已确认的案例边界，不包含 API Key、课程原始 PPT、老师原始稿件、对标账号 Word、协会 PDF 或客户原始资料。

如需使用私人原始资料，请在对应电脑上单独提供，不要提交到仓库。
